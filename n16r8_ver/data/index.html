Hiệu ứng LED RGB (WS2812)

Đang chạy

Tùy chỉnh hiệu ứng LED RGB tích hợp trên board ESP32-S3 (chân GPIO 48). Đèn tự động đổi sang chớp đỏ khẩn cấp khi xe ngã.
